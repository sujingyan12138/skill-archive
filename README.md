# Skill 归档

这个仓库用于存档自建或下载后觉得有价值的 skill。

## 结构

- `项目/`：按具体项目归档，一个项目目录里可以放多个该项目会用到的 skill。
- 其他中文目录：按 skill 的用途做简短分类，每个分类目录下放一个对应的原始 skill 文件夹，方便保留原始名称和内部结构。
